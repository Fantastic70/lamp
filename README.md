# AL ARAB ARCHITECTURE - LumiArch Pro 💡

![Logo](logo.png)

## 📌 نبذة عن التطبيق
**LumiArch Pro** هو تطبيق ويب وهاتف محمول (PWA) مطوّر خصيصاً للمهندسين المعماريين والمصممين لحساب احتياجات الإضاءة الفنية (Illuminance Calculation) للفراغات السكنية والإدارية بدقة عالية اعتماداً على المعايير الهندسية المعتمدة (**CIBSE / IESNA**).

---

## 🛠 المميزات الهندسية
* **طريقة حساب التدفق الضوئي (Lumen Method):**
  $$\text{Total Lumens} = \frac{\text{Lux} \times \text{Area}}{\text{UF} \times \text{MF}}$$
* **تحديد المساحة:** إدخال الأبعاد (طول × عرض) أو المساحة المباشرة ($m^2$).
* **توزيع الوحدات (Fixtures):** اقتراح تلقائي لعدد الكشافات والسبوتات (7W, 12W, 18W, 24W).
* **حماية وتأمين:** شاشة دخول مخصصة بكلمة سر (`ALARAB2026`).
* **تطبيق تقدمي (PWA):** قابل للتثبيت التلقائي على أجهزة Android و iOS والعمل بدون إنترنت.
